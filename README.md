## Project Intro/Objective

The main purpose of this project is to analyze credit card customer data
to identify characteristics associated with a higher risk of default.

The project will use statistical analysis and classification algorithms
covered in AAI-500 to investigate whether historical payment behavior,
credit information, and customer characteristics can help identify
higher-risk clients. Multiple classification models will be evaluated
to determine how their performance differs when predicting customer default.

## Project Description

### Dataset

This project uses the **Default of Credit Card Clients** dataset.

The dataset contains information about credit card customers, including
demographic characteristics, credit limits, repayment history, bill
statements, previous payment amounts, and whether the customer defaulted
on the following month's payment.

The dataset contains approximately 30,000 customer observations. The
exact dimensions and variable definitions will be verified during the
data preparation stage of the project.

### Research Question

Can historical payment behavior, credit information, and customer
characteristics be used to identify clients at higher risk of default,
and which classification model provides the most useful performance?

### Analysis

The project will include:

1. Data cleaning and preparation
2. Exploratory data analysis
3. Descriptive and inferential statistical analysis
4. Data visualization
5. Baseline classification
6. Logistic regression
7. Decision tree classification
8. Ensemble classification
9. Model evaluation and comparison

Model performance will be evaluated using appropriate classification
metrics, including:

- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC
- Confusion Matrix

### Questions to Explore

- What percentage of customers in the dataset defaulted?
- Which customer characteristics are associated with default?
- How does previous repayment behavior relate to future default?
- Are credit limits, bill amounts, or payment amounts associated with default?
- Which classification model is most useful for identifying customers
  who may be at higher risk of default?
- How do precision and recall differ among the models?
